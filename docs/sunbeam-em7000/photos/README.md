# Photographs of the machine as found

Photographs of the reference machine, taken by its owner during the as-found inspection (October 2026). The owner releases each into the public domain, on the same terms as the rest of this repository. They are reduced to at most 1600 px on the long side and re-encoded as JPEG; the originals are the owner's.

Each photograph supports the entries of the record that cite it by file name.
