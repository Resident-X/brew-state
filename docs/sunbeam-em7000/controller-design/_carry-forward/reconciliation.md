# Reconciliation of the earlier design folder with the machine record

Written 2026-10-23. This is a change record. It compares each document that exists both in the machine record's root (`docs/sunbeam-em7000/`) and in this folder with its root document, classifies every differing passage or row, and records where each fact still true was carried and why the rest is marked superseded. It also records the corrections made to the root derived views. Nothing was removed or moved.

The copies in this folder are earlier forks, refreshed 2026-10-12 for the bought-module design. The root documents govern; where the two differ, the copy loses (README.md).

## Classes

- **a** still true and absent from the root: carried into the root `controller-io.md`, a root derived view, or (for facts about the custom board's parts) a retained data file in this folder, at its existing path. Where a fact was already held in a retained data file or in the constraints record it is listed as held there, with no edit.
- **b** superseded, or method of the bought-module design only: marked in place in the copy with a short bracketed note (at the section or, in a table, as a prefix in the row's first cell or in a CSV row's last cell). The copy's own content is not rewritten.
- **c** already carried: the root says the same thing in different words.
- A passage that is partly a and partly b is a hybrid (written a+b): the part that still holds was carried and the rest marked. Hybrids are counted once under each class. Trivially equal rewordings are grouped into one row per section.
- **root only**: a row of the root absent from the copy (the copy dropped it).

When a fact's standing was unclear it was treated as a and carried.
