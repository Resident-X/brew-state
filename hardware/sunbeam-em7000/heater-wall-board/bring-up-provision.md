# Bring-up provision: Sunbeam EM7000 heater wall board

Test points, isolating links, first-power current limiting and the pin classification of every connector, terminal, header and tab of the heater wall board, kept to the method in `docs/board-design-method.md` ("Designing for bring-up and a second spin") and the form of the main board's `bring-up-provision.md`. Part references are those of `schematic-spec.yaml`.

**What the board is.** A passive switch pair. It produces no rail, holds no regulator and runs no code. Its only supply is the LED supply `+5V_WB`, which enters on the header J931 from the main board, where it leaves through the isolating link JP761 with its test point TP761 on the load side. The two heaters' mains current does not come from this board: it flows through each element, the triac and the return, and the element's live feed is the main board's.

**No test point is placed on this board.** The committed schematic carries none and no part of this record changes it. Each net below is probed at the pad or pin the row names. A test point per switch node would sit on a mains net: the mains nets are touched with a probe only with the cable to the main board unplugged or with mains removed.

## Pins of every connector, terminal, header and tab

| Pin | Net | Class | Why |
|---|---|---|---|
| J911.1 | OUT_C | signal | blade: the coffee element lead landing; the new wire runs to the element's in-line joiner. The triac switches the element's neutral side, so nothing is fed in through it by this board |
| J921.1 | OUT_S | signal | blade: the steam element lead landing, as J911 |
| J931.1 | +5V_WB | supply_input | LED supply from the main board's J761.1 (through JP761); the only supply that enters this board, feeding the two LED anodes |
| J931.2 | HEAT_C_LED_K | signal | coffee opto-triac LED return, sunk by the main board's Q761 |
| J931.3 | HEAT_S_LED_K | signal | steam opto-triac LED return, sunk by the main board's Q771 |
| J941.1 | RET | signal | blade: the common triac return; the wire runs to the main board's WB_RET blade J110 on its NEUTRAL pour (owner decision D8 drawn at the blade) |
