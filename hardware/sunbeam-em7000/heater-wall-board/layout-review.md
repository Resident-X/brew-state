# Layout review of the heater wall board

The review of `hardware/sunbeam-em7000/heater-wall-board` by the [Layout review](../../../docs/board-design-method.md#layout-review) step of the board design method. Each round is recorded at its end, before any change to the board it calls for. Round 1 was judged by one reviewer, a session that did not design the board, from the board's design files, the checklist (the catalogue's 70 items and the board's own items BOARD-1 to BOARD-18 of `layout-plan.md`), the layout review views, the placement view, the pre-order check's lines and the committed `layout-plan.md`.

## Round 1

- **Board judged**: 6e36597d4db364a581aadd6964c736611ec3e946, the commit holding the design files as they stand: the router's commit b5f2547d with text-only property changes (the opto-triac part fields).
- **Views**: the commands the views were rendered with, as run from a detached worktree of the commit outside the repository (`git worktree add --detach <scratch>/wall-r1 6e36597d4db364a581aadd6964c736611ec3e946`; `<scratch>` is the reviewer's scratch folder), with `KICAD_CLI=/Applications/KiCad/KiCad.app/Contents/MacOS/kicad-cli`; the classes are the critical classes routing locked:

```
(cd <scratch>/wall-r1/hardware/sunbeam-em7000/heater-wall-board && task hw:views -- --board heater-wall-board.kicad_pcb --project heater-wall-board.kicad_pro --class Mains --class MainsTrunk --class MainsBranch --out <scratch>/hwb-views-1)
(cd <scratch>/wall-r1/hardware/sunbeam-em7000/heater-wall-board && task hw:placement -- --board heater-wall-board.kicad_pcb --project heater-wall-board.kicad_pro --out <scratch>/hwb-placement-1)
```
