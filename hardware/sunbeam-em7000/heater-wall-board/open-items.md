**Requirement to carry to the graph (firmware and sensing; the main session authors the node).** The stuck-on current threshold of the supply-current check (the check that reads a heater's current while it is commanded off) must be set so that it trips at 2.0 A or less, so that the 2.7 A rms of a partly failed wall varistor fed through a 47 ohm element (253^2 / (4 x 47) = 340 W, `W_margins.py` section d) is seen.
